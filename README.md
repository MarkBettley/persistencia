# Persistencia con Java

Proyecto académico desarrollado durante la formación Backend Java de EBAC para practicar mecanismos de persistencia y acceso a datos.

## Objetivo

Aplicar conceptos de almacenamiento, recuperación y manipulación de información desde aplicaciones Java.

## Tecnologías

- Java
- Persistencia de datos
- SQL
- Maven

## Uso

Clona el repositorio y abre el proyecto en un entorno de desarrollo compatible con Java.

Revisa la configuración del proyecto y de la base de datos antes de ejecutar los ejercicios.
